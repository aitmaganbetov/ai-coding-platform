## 2. Структурные несоответствия `.md`-версии

- В `.md` заголовки §1, §5, §13, §14, §20 пусты, а их содержимое сдвинуто в соседние разделы (преамбула, конец §4, конец §12, конец §19). В PDF разделы на своих местах (см. §0).
- «миграцией --» в `.md` — в PDF «миграцией БД» (совпало с восстановлением).

## 3. Неоднозначности и принятые решения

| Вопрос | Решение | ADR |
| --- | --- | --- |
| Имена stack-ов в FR-02 (`React/TS`) | Раздельные значения `react`, `typescript`, `javascript`; `laravel` дополняет `php` | ADR-0004 |
| Где enforced «no auto-merge» | Неотключаемый инвариант конфигурации + проверка в GitHub-адаптере (S4) | ADR-0004, ADR-0015 |
| Что такое «Agent» как роль RBAC | Технический субъект с краткоживущими правами на задачу (`AgentScope`) | ADR-0010, ADR-0011 |
| Очередь без Redis | БД-очередь по умолчанию, Redis — адаптер | ADR-0013 |
| Имена reusable workflows конфликтуют с CI самого проекта | CI проекта — `ci.yml`, `repo-security.yml`; имена из §9 зарезервированы | ADR-0015 |
