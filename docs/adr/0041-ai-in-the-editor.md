# ADR-0041: ИИ в редакторе

- Статус: Принято
- Дата: 2026-11-06
- Уточняет: [ADR-0037](0037-ai-chat-agents.md), [ADR-0040](0040-ai-changes-review.md)

## Контекст

Изменения агента можно было проверить только в отдельном списке (ADR-0040), а обратиться к ИИ — только из чата, вручную описав, о каком коде речь. Требование интерфейса — работа с ИИ прямо в Code Studio.

Агенты платформы — Claude Code и Codex в контейнере пользователя. Каждый их ответ — это полный ход агента, он длится секунды. Для автодополнения на лету («призрачный текст», как у Copilot) нужна модель, которая отвечает за десятки миллисекунд при каждом нажатии клавиши. CLI-агенты для этого не предназначены, а отдельный API-провайдер под это в платформе не настроен.

## Решение

1. **Изменения агента в коде.** Открытый файл рабочей области размечается по его фрагментам «на проверке» (тот же `GET …/workspace/diff`):
   - добавленные и изменённые строки подсвечены;
   - над каждым фрагментом стоит виджет с удалёнными строками (зачёркнуты) и кнопками «Принять» / «Отклонить». Это те же действия, что в проверке изменений (`git apply --cached` / `git apply -R` в контейнере).

   Пока в редакторе есть несохранённые правки, разметка скрыта: строки могли сдвинуться. После хода агента файл и разметка обновляются.

2. **ИИ над выделением.** Над выделенным кодом появляется панель: «Объяснить», «Исправить», «Улучшить», «Тесты», «Спросить…» (`Ctrl+I` — «Спросить…» для выделения или текущей строки).
   - Запрос уходит в чат этой рабочей области с путём файла, номерами строк и кодом.
   - «Спросить…» кладёт текст в поле ввода, чтобы пользователь дописал вопрос. Остальные действия отправляются сразу. Если агент ещё занят, запрос ждёт в поле ввода.
   - Ответ и изменения агента появляются в чате, а изменения ещё и в редакторе, где их принимают или отклоняют по фрагментам.

   Работает в собственной рабочей области. В файлах проекта, открытых только для чтения, панели нет.

3. **Двоичные файлы и изменения без фрагментов** (режим, имя) принимаются и откатываются целиком (ADR-0040): `git add`, `git restore --worktree`, `git restore --staged`.

4. **Реализация.** Расширения CodeMirror 6 (подсветка строк, блок-виджеты, панель над выделением) стилизуются через `EditorView.baseTheme` (adoptedStyleSheets, совместимо со строгой CSP). Связь редактора и чата — через небольшое хранилище запросов (`web/src/review/inline.ts`). Редактор следует теме NEXUS, а не теме ОС.

## Последствия

- Изменения агента проверяются там, где читается код. Обратиться к ИИ можно не покидая редактор.
- Автодополнения «призрачным текстом» нет. Его можно добавить отдельным решением, когда у проекта будет быстрый ИИ-провайдер (API или локальная модель) и решение о передаче кода этому провайдеру.
- Проверки:
  - компонентные тесты (размещение фрагментов по строкам, тексты запросов, доставка запроса в чат);
  - сквозная проверка `web/e2e/editor.mjs` в настоящем контейнере: разметка, отклонение и принятие в редакторе, запрос из выделения в чат.

## Альтернативы

- **Monaco с его inline-API.** Отклонено, как и в ADR-0039: CodeMirror уже встроен и даёт те же разметку и виджеты.
- **Автодополнение через CLI-агента.** Отклонено: секунды на каждый ответ и полный ход агента по подписке пользователя на каждое нажатие клавиши.
