# ADR-0003: Модульный монолит, порты и адаптеры

- Статус: Принято
- Дата: 2026-11-05

## Контекст
Три режима запуска (Local, Self-Hosted, GitHub Hybrid) используют одно ядро. ТЗ §4 требует заменяемых интеграций (Git adapters, executors, LLM adapters, хранилище). Команда небольшая, срок 18 недель — микросервисы избыточны.

## Решение
Один Python-пакет `ai_coding` с явными слоями (снизу вверх):

1. `domain` — перечисления и сущности, чистый Python без I/O.
2. `security` — redaction, детектор секретов, политики (зависит только от `domain`).
3. `contracts`, `detection`, `git` (и далее `persistence`, `executors`, `llm`, `tools`) — порты (`Protocol`) и адаптеры.
4. `config` — модели и валидация конфигурации.
5. `orchestrator`, `agents`, `quality`, `workflows`, `reports` (S2+) — прикладная логика, зависит только от портов.
6. Точки входа: `cli` (Typer), `api` (FastAPI, S8), `worker` (S8) — собирают адаптеры (composition root).

Правила:
- Прикладной слой зависит от **портов**, а не от адаптеров; адаптер выбирается конфигурацией.
- Адаптеры не импортируют друг друга.
- Слои проверяются `import-linter` в CI (`[tool.importlinter]` в `pyproject.toml`); при добавлении модуля контракт расширяется в том же PR.
- Внешние расширения регистрируются через entry points (`ai_coding.agents`, `ai_coding.tools`, `ai_coding.executors`, `ai_coding.llm_providers`) — S3/S5.

## Последствия
Local Lite — тот же код без API/worker. Self-Hosted разворачивает FastAPI + worker из того же пакета. Если в будущем потребуется вынести worker в отдельный сервис — граница уже проведена по портам.

## Альтернативы
Микросервисы — отклонено (операционная сложность, не нужна для NFR-02 «10 параллельных заданий»). Плагинная архитектура без слоёв — отклонено (нет контроля зависимостей).
