# ADR-0036: Рабочие области и терминал в браузере (Claude Code, Codex на подписках пользователей)

- Статус: Принято
- Дата: 2026-11-06
- Уточняет: [ADR-0018](0018-executors-implementation.md), [ADR-0031](0031-server-deployment-storage-ui.md), [ADR-0033](0033-sandbox-egress-and-e2e-tools.md)

## Контекст

Пользователи хотят разрабатывать прямо в Web UI: видеть файлы проекта, править их и давать задания ИИ. Платить они хотят своими подписками Claude (Pro/Max) и ChatGPT (Plus/Pro), а не API-ключами.

Ограничения вендоров (проверено 2026-11-06):

- Anthropic не разрешает сторонним приложениям предлагать вход claude.ai, отправлять запросы через подписку от имени пользователей, а также собирать, хранить или пропускать через себя токены claude.ai. Исключение — пользователь сам входит в **неизменённый** Claude Code своей подпиской, в том числе когда Claude Code размещён на платформе. Источник: code.claude.com/docs/en/legal-and-compliance.
- OpenAI поддерживает вход в Codex CLI через ChatGPT, в том числе на удалённых машинах (`codex login --device-auth`). Для программного использования OpenAI рекомендует API-ключ.

Отсюда: окно промптов, которое платформа отправляет «по подписке пользователя», недопустимо. Допустимо дать пользователю терминал с официальными CLI, где он входит сам.

## Решение

1. **Рабочая область** — собственный клон репозитория проекта у каждого участника: `<data>/workspaces/<project>/<user>/repo`.
   - Клон делает сервер. Конфигурация источника не копируется.
   - Remote `origin` указывает на origin проекта (GitHub и т. п.): пользователь пушит своими учётными данными, как в VS Code.
   - Remote `project` — репозиторий проекта, смонтированный только для чтения в `/project`.
   - Участники не видят рабочих областей друг друга.
2. **Терминал** — контейнер на пару «пользователь × проект» из образа `ai-coding-workspace` (`deploy/workspace/`).
   - В образе: официальные Claude Code и Codex (версии старше двух недель), git, Node.js, Python, tmux.
   - Изоляция:
     - `--read-only`, `--cap-drop ALL`, `no-new-privileges`, uid сервера, лимиты CPU/памяти/pids;
     - опционально gVisor;
     - без сокета Docker;
     - сеть — только через allowlist-прокси ADR-0033, хосты в `AI_CODING_SERVER_WORKSPACE_EGRESS`.
   - Монтирования: рабочая область (`/workspace`), домашняя папка пользователя (`<data>/homes/<user>`, только его контейнерам) и проект только для чтения.
   - Вход в Claude и ChatGPT живёт в домашней папке пользователя. Платформа его не читает, промптов не видит.
   - Сеанс — tmux: закрытая вкладка отсоединяется, Claude Code продолжает работать. При закрытии вкладки её tmux-клиент отсоединяется по PID: процесс `docker exec` в контейнере сам не завершается. Контейнер без подключённых терминалов дольше `WORKSPACE_IDLE_MINUTES` удаляется; рабочая область и домашняя папка остаются.
3. **Файлы в Web UI** читает и пишет сервер (`api/files.py`).
   - Пользователь управляет каталогом (у него shell), поэтому путь проходится по компонентам от дескриптора каталога с `O_NOFOLLOW`. Ссылка, даже подменённая во время запроса, не уводит за пределы рабочей области.
   - Файлы открываются с `O_NONBLOCK`, FIFO не вешает запрос.
   - Сохранение атомарное. Оно проверяет версию, загруженную редактором: если файл изменил Claude Code в терминале, ответ — 409.
   - `.git` недоступен.
4. **Git рабочей области выполняется только в контейнере пользователя** (`docker exec`), никогда на сервере.
   - `.git/config` пишет пользователь. `core.fsmonitor`, фильтры, `gpg.program` заставили бы серверный git запускать команды.
   - «Отправить в проект»: контейнер выдаёт git bundle (просто данные), сервер забирает его в репозиторий проекта веткой `ws/<user>/<ветка>`. Ветки проекта не трогаются.
5. **Транспорт** — WebSocket `/api/v1/projects/{id}/workspace/terminal`.
   - Токен передаётся первым сообщением: браузер не умеет ставить заголовки на WebSocket, а токен в URL попал бы в логи.
   - Права: `workspace.use` (owner, maintainer, developer), просмотр файлов — `files.view` (плюс auditor).
6. **Где запускаются контейнеры.** API смотрит в интернет и доступа к Docker не имеет (ADR-0018).
   - В docker-compose контейнеры запускает отдельный сервис `ai-coding server workspaces` с сокетом Docker. API обращается к нему по внутренней сети с HMAC-тикетами (`AI_CODING_SERVER_WORKSPACE_SECRET`, 60 с). Сервис сам перепроверяет роль: тикет удостоверяет только, кто спрашивает.
   - В однопроцессной установке (`serve --with-worker`) контейнерами управляет сам API (`AI_CODING_SERVER_WORKSPACES=local`).
7. **CSP.** `style-src` разрешает inline-стили: xterm.js задаёт размеры и тему элементами `<style>`. `script-src` остаётся `'self'`, `unsafe-eval` запрещён. CodeMirror вставляет стили через `adoptedStyleSheets`.

## Последствия

- Разработка с Claude Code и Codex на подписках пользователей, не нарушающая правила вендоров. Платформа не хранит и не передаёт токены подписок.
- У каждого участника появляется shell на сервере: изолированный, без привилегий и с ограниченной сетью, но это всё равно новая поверхность атаки. Терминалы выключаются (`AI_CODING_SERVER_WORKSPACES=off`), образ и список хостов настраиваются.
- Диск: клон проекта на каждого участника.
- Ограничение сети действует только для HTTPS через прокси: git по SSH из терминала недоступен, используется HTTPS-токен.
- Перезапуск сервера отсоединяет все терминалы. Сеансы tmux в живых контейнерах сохраняются.

## Альтернативы

- **Окно промптов в UI, отправляемых через подписку пользователя** (`CLAUDE_CODE_OAUTH_TOKEN`, вход ChatGPT, хранящийся на сервере). Отклонено: прямо запрещено Anthropic, у OpenAI не подтверждено. Окно промптов на API-ключах остаётся возможным отдельным решением.
- **Общий рабочий каталог проекта для всех участников.** Отклонено: участник мог бы подложить в общий каталог `.claude/settings.json` с хуками или git-конфиг и украсть вход другого участника, когда тот запустит Claude Code.
- **git worktree вместо независимого клона.** Отклонено: worktree делит `.git` (конфиг и хуки) с репозиторием проекта.
- **Доступ API к Docker.** Отклонено: компрометация API, открытого в интернет, дала бы root на хосте.
