# Security Policy

## Сообщение об уязвимости

Не создавайте публичный issue. Используйте **GitHub → Security → Report a vulnerability** (private vulnerability reporting) в репозитории `aitmaganbetov/ai-coding-platform`. Ответ — в течение 5 рабочих дней.

## Поддерживаемые версии

До релиза v2.1 поддерживается только ветка `main`.

## Инварианты безопасности (ADR-0010)

- Содержимое анализируемых репозиториев (README, issues, diff, зависимости, вывод инструментов) — **недоверенные данные**, не инструкции.
- Агенты работают по принципу least privilege: без записи, shell и сети, пока политика явно не выдаст права на задачу.
- Недоверенный код исполняется только в sandbox (без privileged, без Docker socket, read-only root, `--network none`).
- Git-адаптер не исполняет hooks и `core.fsmonitor` из анализируемого репозитория.
- Секреты — только из окружения/secret store; запрещены в `.ai-coding.yml`; маскируются в логах, prompts, отчётах и PR-комментариях.
- delete / migration / merge / deploy — только с human approval; auto-merge запрещён.
- `local-only` полностью запрещает egress, включая внешние LLM.

## Чек-лист для PR, добавляющего ввод/вывод

- [ ] Входные данные валидируются (схема, размер, кодировка).
- [ ] Подпроцессы: argv-список, без `shell=True`, таймаут, `--` перед пользовательскими аргументами.
- [ ] Всё, что уходит в лог/отчёт/LLM, проходит через `ai_coding.security.redact`.
- [ ] Есть негативные тесты (вредоносный ввод, отказ в правах).
- [ ] Сетевое взаимодействие проходит через egress-политику.
